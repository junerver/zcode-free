识别逻辑 两次模型调用 + 若干本地判定
01截图本地 · 无网络
  • 先置顶 ZCode(必要时复位窗口位置),再抓屏
  • mss 全屏抓取 → 按窗口矩形裁剪出「窗口图」
  • 锁屏由系统 API 判定;纯色画面视为「未渲染」,继续等待
02定位 · 模型调用 ①DeepSeek 视觉
  • 目标不是「福利页」,而是浮在界面上的推广卡片:固定在窗口左下角,含 "ZCODE Weekend Build"、"300,000,000 Tokens",右下角有「领取」小按钮
  • 输出:scene / claimable / card_visible / button_found / button_box(归一化 0~1) / ocr_texts / confidence / notes
  • 结构化保障:Prompt 含 JSON 示例 + response_format + 本地 JSON 修复
03点击本地
  • 取 button_box 中心 → 归一化坐标
  • 屏幕坐标 = 窗口矩形原点 + 归一化 × 矩形尺寸
  • pyautogui 点击(鼠标甩到左上角可急停),再进入等待结果
04等待结果 · 模型调用 ②DeepSeek 视觉
  • 点击后不立刻下结论:在「等待领取结果上限」(默认 90s)内反复截图判定,直到出现明确结论
  • 结果形态:成功 =「领取成功 + 开始体验」,失败 =「领取失败 + 知道了」,加载中 = 按钮转圈 / 含加载词
  • 加载中不算失败,继续等;每张校验图都留档,可在运行日志里回放结果是怎么出来的
  • 输出:success / failed / claimed / pending / card_visible / popup / keywords / confidence
